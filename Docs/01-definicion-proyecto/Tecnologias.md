# E. Tecnologías Seleccionadas

A continuación, se mencionan los entornos de desarrollo, plataformas y herramientas empleadas en la implementación del sistema.

| Categoría | Tecnología | Uso |
|---|---|---|
| **Backend** | Laravel (PHP) | Framework principal del sistema, siguiendo el patrón MVC (Modelo-Vista-Controlador). |
| **Base de datos** | MySQL | Almacenamiento de la información de inventario, ventas, empleados y gastos. |
| **Frontend** | Bootstrap | Framework CSS para una interfaz responsive, consistente con la identidad visual del negocio (verde esmeralda, dorado, blanco y negro). |
| **Control de versiones** | Git y GitHub | Control de versiones del código fuente y trabajo colaborativo en equipo. |
| **Documentación** | Markdown / arc42 / PlantUML | Documentación técnica del proyecto (definición, requerimientos, arquitectura). |
| **Gestión ágil** | Jira | Gestión del backlog y planificación de sprints. |

Todas las herramientas seleccionadas son de código abierto o de uso gratuito, lo cual es coherente con la restricción de costo del proyecto y con el hecho de tratarse de un desarrollo propio de bajo costo frente a soluciones comerciales como Siigo, Alegra o SAP Business One.
