# Requisitos Funcionales Principales - ERP LA 74


| Código | Requisito |
|---|---|
| RF01 | El sistema deberá permitir registrar productos por categoría. |
| RF02 | El sistema deberá registrar entradas y salidas de inventario. |
| RF03 | El sistema deberá generar alertas cuando el stock esté por debajo del mínimo definido. |
| RF04 | El sistema deberá registrar compras a proveedores. |
| RF05 | El sistema deberá registrar ventas de productos. |
| RF06 | El sistema deberá calcular el margen de ganancia por producto y por categoría. |
| RF07 | El sistema deberá gestionar empleados, turnos y horarios. |
| RF08 | El sistema deberá calcular y registrar la nómina de empleados. |
| RF09 | El sistema deberá registrar y clasificar los gastos del negocio. |
| RF10 | El sistema deberá mostrar reportes de inventario. |
| RF11 | El sistema deberá mostrar reportes de ventas y márgenes. |
| RF12 | El sistema deberá mostrar reportes de gastos. |
| RF13 | El sistema deberá mostrar reportes de empleados y costos de nómina. |
| RF14 | El sistema deberá permitir gestionar usuarios y permisos. |
