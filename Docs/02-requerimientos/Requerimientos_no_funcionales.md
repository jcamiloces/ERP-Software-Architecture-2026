# Requisitos No Funcionales - ERP LA 74

| Requisito no funcional | Descripción | Justificación |
|---|---|---|
| 1. Usabilidad | Interfaz sencilla e intuitiva para que empleados con pocos conocimientos técnicos puedan usarla fácilmente. | Facilita el registro de ventas e inventario en el día a día y reduce errores operativos. |
| 2. Seguridad | Autenticación de usuarios y control de permisos por roles (administrador, empleado, cajero, bodega). | Protege la información financiera y del inventario del negocio. |
| 3. Rendimiento | Las operaciones comunes (ventas, consulta de stock, reportes) deberán ejecutarse en pocos segundos. | Evita demoras en la atención al cliente y mejora la productividad. |
| 4. Disponibilidad | El sistema debe estar disponible durante el horario de funcionamiento y contar con copias de respaldo. | Evita interrupciones en el negocio y pérdidas de información crítica. |
| 5. Escalabilidad | El sistema debe permitir agregar nuevas categorías, usuarios y módulos sin afectar su funcionamiento. | El negocio puede crecer y el sistema debe adaptarse a nuevas necesidades. |
| 6. Compatibilidad | Debe funcionar correctamente en navegadores modernos y en dispositivos móviles. | Permite acceder al sistema desde diferentes equipos y dispositivos. |
| 7. Mantenibilidad | Código organizado y documentado para facilitar actualizaciones y correcciones futuras. | Reduce costos de mantenimiento y permite mejoras continuas. |
| 8. Diseño de interfaz | Diseño moderno y consistente con la identidad visual del negocio (verde esmeralda, dorado, blanco y negro). | Refuerza la identidad de la marca y mejora la experiencia del usuario. |
